# Goodwill Security Limited

**Live site:** https://umair-jm.github.io/Client-project-2/

Website for Goodwill Security Limited, a 24/7 security services company in
Papatoetoe, Auckland — static guards, mobile patrols, alarm response, event
and construction site security.

Single self-contained `index.html` (no build step, no dependencies). GitHub
Pages serves it straight from the `main` branch root — commit and push to
deploy.

Photography is from [Unsplash](https://unsplash.com/license) (free for
commercial use). The contact email `info@goodwillsecurity.co.nz` is a
placeholder — replace with the client's real address before handover.
